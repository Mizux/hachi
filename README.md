# Hachi

A monster-catching jrpg like game but in a cyberpunk world.

## Documentation

- [Hachi Type Chart](docs/hachi.md)
- [Pokemon Type Chart](docs/pkm.md)

## Setup

```sh
cargo install trunk
rustup target add wasm32-unknown-unknown
```

## Build & Test

* Linux Terminal: `cargo run --bin hachi`

* Browser: `trunk serve`
